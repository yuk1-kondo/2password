# 2Password — デザイン言語

2026-11-14 / macOS・iOS共通UI、ブラウザ拡張ポップアップ

## 参照と解釈

参照: https://www.nuevo.tokyo/

Nuevo.Tokyoのリダクショニストな構成、余白、モノクロの文字組み、等幅の小さなラベルと和色のグラデーションから着想を得た独自のUI。ロゴ、写真、作品画像、ブランド名の転用はしない。

- 本文は読みやすいシステム書体。メタ情報のみ等幅・小さな英字ラベル。
- 主操作はインク色の矩形。角丸は最小限、影は使わず細い罫線で区切る。
- アイテムの識別はローカルのモノグラム。外部faviconは取得しない。
- グラデーションは入口と未選択状態に限定し、情報のある画面では静かな白黒を優先。
- 日本語の操作ラベルと既存のエラー・復元導線を維持。
- システムのライト／ダーク配色に追従。グラデーションは状態を伝える色として使わない。

## 実装

`apps/apple/Shared/VaultDesign.swift` に共通部品を集約。

- `VaultAccessLayout`: 初期設定とロック解除。760pt以上はアートとフォームの2列、狭い画面では縦に並べてスクロール。
- `VaultSpectrum`: SwiftUIで描画する静的アート。画像・ネットワーク・アニメーション不要。
- `VaultWordmark` / `VaultEyebrow`: 共通の文字組み。
- `InkButtonStyle` / `VaultFieldStyle`: 主操作と入力欄。
- 一覧はOSの選択・検索・ツールバーを維持。iOSのアイテム行はNavigationLinkで詳細へ進む。
- 詳細は余白と罫線で整理。アイテム変更時にパスワード表示状態をリセット。
- `apps/extension/popup.css`: 同じ構成とライト／ダーク配色。

## 検証

- macOS Debugビルド成功（署名なし）。
- iOS Simulator向けビルド成功（署名なし）。
- 拡張の登録回帰テスト2件成功。
- Mac解除後、macOSのロック解除画面・空の保管庫・追加フォームを目視確認。追加フォームのキャンセルから一覧へ戻る操作も確認。
- 保管庫が0件のため、データのある一覧・詳細は未確認。狭い画面・ダークモード・長いタイトル・iOSキーボード表示も追加確認が必要。
- Android・WindowsのUIは今回の適用対象外。
